# Hiện sinh — Public Encounter Package

**English access rendering. The Vietnamese [README.md](README.md) is canonical and governs if the versions differ.**

This is the public access layer of **“Hiện sinh.”** It opens an encounter and provides enough information to assess the ontology, provenance model, transaction structure, and legal perimeter. It does not contain the Frame practice, canonical Painting archive, original ritual transcript, or operator secrets.

## The work

“Hiện sinh” distinguishes three things that must not be collapsed:

- **Frame — 9 configurations/works:** each Frame opens conditions for a distinct encounter and event. Eight Frames are issued independently; Frame 05 is issued only inside Package 05.
- **Painting — canonical embodiment 1/1:** the canonical embodiment of the event that occurred beneath the brush in Package 05; the Painting has no separate token.
- **Package 05 — the sole Complete:** contains **Frame 05 + Painting** and is acquired directly as token ID #05. It is not an upgrade from a previously purchased Frame.

Ontology:

```text
idea/seed → Frame → generative event → Painting
→ recognition/designation/transmission → encounters → possible stewardship
```

Read [WORK-ONTOLOGY.en.md](WORK-ONTOLOGY.en.md) before token or license documents.

## Three relationship and package states

1. **Public Encounter:** this folder only.
2. **Frame Practice:** Public Encounter + delivery scope for one of eight Frame-only sales packages; no Painting or original L transcript.
3. **Package 05 / Complete Stewardship Archive:** Public Encounter + Frame 05 + canonical Painting archive and care records. There is no Painting-only package.

PUBLIC and the practitioner-bearer use the same intentionally transformed Public Encounter Representation. It is not a preview, teaser, or lower tier; a Frame does not purchase more pixels or a superior way of perceiving. The canonical Painting appears only in the Complete archive because that archive includes the canonical embodiment.

The three primary brushstrokes arise from the shared Public Encounter Representation itself. There is no separate viewing of the canonical Painting before acquisition; the canonical Painting is delivered only inside Package 05 after acquisition is complete.
